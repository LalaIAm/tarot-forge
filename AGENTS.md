# Agent memory

## Learned User Preferences

- Prefer React front end and Python backend for full-stack apps.

## Learned Workspace Facts

- Vibe Tarot deliverable: card concepts, generated art per card, and
  printable/exportable deck (e.g. zip, PDF).
- Style bible is generated first and must be user-approved before deck
  generation starts.
- Style-bible crew includes a Style Researcher agent (in addition to Creative
  Director and Designer).
- After each card image is generated, a vision-capable evaluator approves or
  sends the card back; refiner produces updated prompt and flow goes back to the
  image API (not directly to evaluator).
- Session-based usage first; data model is ready for accounts later.
